# 🚀 Task Manager MERN App

A modern full-stack Task Manager application built using the MERN stack with a clean responsive UI, task statistics, CRUD operations, and real-time task updates.

🌐 **Live Demo:** [https://task-manager-mern-3hv5.onrender.com/](https://task-manager-mern-3hv5.onrender.com/)

---

# ✨ Features

## ✅ Task Management

* Create new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Dynamic task counters

## 📊 Statistics Dashboard

* Total tasks count
* Completed tasks count
* Remaining tasks count
* Progress tracking
* Category-based statistics

## 🎨 Responsive UI

* Mobile responsive design
* Modern dark theme
* Interactive buttons & hover effects
* Clean task cards
* Modal-based task creation

## ⚡ Full Stack Functionality

* REST API integration
* MongoDB database storage
* Real-time UI updates
* Express backend APIs
* Axios API handling

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Kartikey7081/task-manager-mern.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
cd Frontend
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd Backend
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the Backend folder.

```env
MONGO_URI=your_mongodb_connection_string
PORT=3000
```

---

# ▶️ Run Project

## Start Backend

```bash
cd Backend
npm start
```

---

## Start Frontend

```bash
cd Frontend
npm run dev
```

---

# 📡 API Endpoints

## Get All Tasks

```http
GET /api/notes
```

---

## Create Task

```http
POST /api/notes
```

---

## Update Task

```http
PATCH /api/notes/:id
```

---

## Delete Task

```http
DELETE /api/notes/:id
```
